Este documento é um plano de trabalho. Cada integrante deve implementar, revisar e registrar no GitHub somente a parte que realmente realizou.

Visão do fluxo

A rota inicial abre a busca de barbearias. Usuários visitantes podem navegar por estado e cidade; quando precisarem acessar a conta, seguem para login ou cadastro. Depois de entrar ou confirmar o e-mail, retornam para a listagem.

Ordem de execução e integração

  1. Gabriel confirma as rotas e as respostas esperadas da busca.
  2. Douglas define e testa os métodos de autenticação usados por login e cadastro.
  3. Ana Clara conecta o cadastro e a confirmação de e-mail ao serviço de autenticação.
  4. Samuel finaliza a interface da listagem usando os estados fornecidos pela busca.
  5. O grupo testa o fluxo completo: abrir busca → entrar/cadastrar → voltar à busca → selecionar estado e cidade → resultado com lista, vazio e erro.

Checklist antes de cada commit

  • Alterar apenas os arquivos atribuídos ao card, salvo alinhamento prévio com o grupo.
  • Rodar npm run build sem erros.
  • Testar manualmente a tela afetada e a rota de retorno para /barbearias.
  • Descrever no commit o que foi implementado de fato.
